# Five-Minute Demo Script

1. Open the dashboard and explain the verification-first value proposition.
2. Show the map and analytics updating from the same verified dataset.
3. Open **Explore**, filter by type/country and inspect a record's hierarchy and evidence.
4. Open **Submit data**, enter a new deployment and public evidence URL.
5. Show that the submitted record is pending and absent from the default public registry.
6. Open **Moderate**, enter the admin key, review the evidence and approve the record.
7. Return to the registry/dashboard and show that the approved record now appears.
8. Open `/docs` to demonstrate the documented API and testable architecture.
